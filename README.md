🎮 PS3 Icon Tool - Customizer

PS3 Icon Tool es una aplicación de Android diseñada para personalizar la apariencia de tus juegos instalados en una PlayStation 3 (HEN/CFW) de forma remota, rápida y sin necesidad de usar una computadora o memorias USB.

Con esta herramienta, puedes cambiar iconos y fondos de pantalla del XMB directamente desde la galería de tu celular a través de una conexión FTP.

    🖼️ Cambiar Iconos: Actualiza el ICON0.PNG de cualquier juego.

    📜 Ahora permite editar el nombre de los juegos del xmb

    🌆 Personalizar Portadas: Modifica el fondo que se ve al seleccionar un juego (PIC0.PNG, PIC1.PNG, PIC2.PNG).

    🧹 Limpieza de XMB: Elimina sonidos molestos (SND0.AT3) o videos de inicio de juego (ICON1.PAM).

    📥 Descarga e Edición Directa: ¿lo quieres en tu celular? La aplicación se encarga de el redimensionamiento automático dependiendo de cada tipo seleccionado

🚀 Cómo se utiliza
1. Preparación en la PS3

    Asegúrate de que tu consola esté conectada a la misma red Wi-Fi que tu celular.

    Debes tener activado el servidor FTP (usualmente activo por defecto en webMAN MOD, multiMAN o IrisMan).

    Anota la dirección IP de tu consola (ejemplo: 192.168.1.15).

2. Conexión desde la App

    Abre PS3 Icon Tool.

    Introduce la IP de tu PS3 en el campo de texto inferior.

    Presiona el botón de Enviar (Check). La app listará todos los juegos instalados en /dev_hdd0/game/.

3. Modificación de Archivos

    Selecciona el juego que deseas editar del listado.

    Elige el modo (ICONO o PORTADA). Si mantienes presionado el botón de Portada, podrás rotar entre PIC0, PIC1 y PIC2.

    Para Cambiar: Presiona "CREAR/CAMBIAR" y elige una imagen de tu galería. La app la redimensionará automáticamente al tamaño correcto para la PS3.

    Para Guardar: Presiona el botón flotante del Check Verde para subir la imagen a la consola.

    Para Borrar: Usa el botón "BORRAR" para eliminar archivos específicos (como música o video de fondo).

4. Ver los cambios

    Una vez que la app confirme el mensaje de "¡Actualizado!", reinicia tu consola o entra y sale de una aplicación para que el XMB refresque las imágenes.
